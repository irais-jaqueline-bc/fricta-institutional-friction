# FRICTA: Institutional Digital Adoption Friction

Research system for modeling digital adoption friction in Mexican residential childcare institutions. Developed for **CONACIC 2026**.

## 🛠 Project Structure
* **data/**: Raw, processed, and anonymized survey data.
* **src/**: Core Python logic for cleaning and scoring.
* **api/**: FastAPI backend for diagnostic services.
* **dashboard/**: Streamlit interface for institutional feedback.
* **paper/**: Research drafts and methodology documentation.
